# Protótipo mobile de coleta em campo

Parte da demonstração integrada Doutor Embalagem. Consulte o [roteiro completo](../README.md) para iniciar o servidor e apresentar dashboard e mobile.

Cadastre primeiro a empresa no dashboard. Ela aparecerá no mobile, onde a consultoria começa sem ambientes. Adicione ambientes, escolha equipamentos do catálogo ou confirme os formulários de exemplo já preenchidos. Confira o resumo e envie ao dashboard para abrir os cálculos e resultados.

Os dados são fictícios e persistem no armazenamento local deste navegador. O mock é compartilhado com o dashboard em `../compartilhado/mock.js`. Use os dois pelo mesmo endereço HTTP e porta. O envio é uma simulação local, sem API, sincronização entre dispositivos, autenticação ou exportação.

Após envio, o mobile exibe o resumo sem edição. Para repetir, use **Reiniciar demonstração** no dashboard.
